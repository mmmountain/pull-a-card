# Prompt

A habit card game for Android. Cards get dealt to your phone as notifications;
play them, hold them, or ask to be reminded later. Friends who enter the same
table name share the table.

## One-time setup
1. Supabase → SQL Editor → paste `supabase/schema.sql` → Run.
2. Push to `main`. GitHub Actions builds `pull-a-card.apk` and attaches it to the latest release.

## Install
On the phone, open this repo's **Releases**, download `pull-a-card.apk`, and open it.
Android will ask to allow installs from your browser once.
